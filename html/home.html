Getting started

  1. Change the default password after your first login to the console.
  2. Fill in the fields on the Configuration page. This is optional, but Falcongate needs these settings to use its full capabilities.
  3. Consider registering for our free cloud API. A key enables advanced features, including regular updates of the block lists for malware domains and IP addresses, and centralized alert reporting over email and Telegram from our cloud servers.

Deployment

Keep these points in mind when deploying Falcongate to a real home or production network:

  • Change the default SSH password on your Falcongate device.
  • Change the default password for the web console admin user.
  • Regenerate the openssh-server certificates for SSH encryption if Falcongate was deployed from an OVA image.
