Welcome to Falcongate

Falcongate monitors your network and alerts you to threats. Use the menu to review alerts, connected devices and network activity.

Getting started

  1. Set a strong password when the console prompts you during the first sign-in.
  2. Fill in the fields on the Configuration page. This is optional, but Falcongate needs these settings to use its full capabilities.
  3. Open System Overview and confirm that all services are running.
  4. Connect a device to the Falcongate network and confirm that it appears on the Status page.
  5. Test detection by running nslookup malware.wicar.org on that device. This only looks up a harmless test domain. A Malware alert should appear on Recent Alerts within about a minute, and by email if you set that up.

Deployment

Keep these points in mind when deploying Falcongate to a real home or production network:

  • Set a strong SSH password on your Falcongate device.
  • Set a strong password for the default admin user when prompted by the web console during the first sign-in.
  • Regenerate the openssh-server certificates for SSH encryption if Falcongate was deployed from a virtual image.
