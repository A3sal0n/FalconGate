Getting started

  1. Change the default password after your first login to the console.
  2. Fill in the fields on the Configuration page. This is optional, but Falcongate needs these settings to use its full capabilities.

Deployment

Keep these points in mind when deploying Falcongate to a real home or production network:

  • Set a strong SSH password on your Falcongate device.
  • Set a strong password for the default admin user when prompted by the web console during the first sign-in.
  • Regenerate the openssh-server certificates for SSH encryption if Falcongate was deployed from a virtual image.
